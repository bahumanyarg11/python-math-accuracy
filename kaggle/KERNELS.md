# Kaggle kernels used for the x86-64 and T4 measurements

Each kernel was generated with `kaggle/make_kernel.py <slug> "<command>" [gpu] [tag]`, which packs the project
(including CORE-MATH, fetched with `scripts/fetch_deps.sh`) into a private Kaggle script kernel and runs the command.
The generated `run.py` files are not included, since they embed a copy of third-party sources. Commands, in run order. Later kernels re-ran or completed parts of earlier ones; the files in `results/` are the final ones described in the paper.

- `pyacc-gate` (CPU): `bash gate/run_gate.sh`
- `pyacc-x86-a` (CPU): `bash kaggle/setup_cpu.sh && NOBESSEL=1 bash drivers/run_all.sh x86_cpu cpu; python3 drivers/provenance.py --tag x86_cpu`
- `pyacc-x86-b` (CPU): `bash kaggle/setup_cpu.sh && bash drivers/run_bessel.sh x86_cpu cpu`
- `pyacc-t4-a` (T4 GPU): `export XLA_PYTHON_CLIENT_PREALLOCATE=false XLA_PYTHON_CLIENT_MEM_FRACTION=.35 NVIDIA_TF32_OVERRIDE=0; bash kaggle/setup_gpu.sh && NOBESSEL=1 bash drivers/run_all.sh t4_cuda cuda jax,torch; python3 drivers/provenance.py --device cuda --tag t4_cuda --libs jax,torch`
- `pyacc-t4-b` (T4 GPU): `export XLA_PYTHON_CLIENT_PREALLOCATE=false XLA_PYTHON_CLIENT_MEM_FRACTION=.35 NVIDIA_TF32_OVERRIDE=0; bash kaggle/setup_gpu.sh && bash drivers/run_bessel.sh t4_cuda cuda jax,torch`
- `pyacc-x86-c` (CPU): `bash kaggle/setup_cpu.sh && python3 drivers/probe_denormals.py --tag x86_cpu && python3 drivers/search.py --fmt binary64 --tag x86_cpu && python3 drivers/search.py --fmt binary32 --tag x86_cpu; python3 drivers/position_test.py; python3 -W ignore drivers/verify.py --tag x86_cpu`
- `pyacc-t4-c` (T4 GPU): `export XLA_PYTHON_CLIENT_PREALLOCATE=false XLA_PYTHON_CLIENT_MEM_FRACTION=.35 NVIDIA_TF32_OVERRIDE=0; bash kaggle/setup_gpu.sh && python3 drivers/probe_denormals.py --tag t4_cuda --device cuda --libs jax,torch && python3 drivers/search.py --fmt binary64 --device cuda --tag t4_cuda --libs jax,torch && python3 drivers/search.py --fmt binary32 --device cuda --tag t4_cuda --libs jax,torch; python3 -W ignore drivers/verify.py --tag t4_cuda --device cuda`
- `pyacc-x86-d` (CPU): `bash kaggle/setup_cpu.sh && python3 drivers/probe_denormals.py --tag x86_cpu && python3 drivers/exhaustive.py --fmt binary16 --tag x86_cpu && python3 drivers/exhaustive.py --fmt bfloat16 --tag x86_cpu && python3 drivers/exhaustive.py --fmt binary16 --bivariate --tag x86_cpu --funcs pow,atan2,hypot && python3 drivers/exhaustive.py --fmt bfloat16 --bivariate --tag x86_cpu --funcs pow,atan2,hypot; python3 drivers/provenance.py --tag x86_cpu`
- `pyacc-x86-e` (CPU): `bash kaggle/setup_cpu.sh && python3 drivers/exhaustive.py --fmt binary32 --tag x86_cpu --funcs exp,exp2,exp10,expm1,log,log2,log10,log1p,sin,cos,tan,asin,acos,atan,sinh,cosh,tanh,asinh,acosh,atanh,cbrt,erf,erfc,lgamma,tgamma`
- `pyacc-x86-f` (CPU): `bash kaggle/setup_cpu.sh && python3 drivers/exhaustive.py --fmt binary32 --tag x86_cpu --funcs y1,y0`
- `pyacc-x86-verify` (CPU): `bash kaggle/setup_cpu.sh && python3 drivers/verify.py --tag x86_cpu`
- `pyacc-t4-bessel` (T4 GPU): `bash kaggle/setup_gpu.sh && mkdir -p results/provenance && python3 drivers/cuda_bessel_probe.py`
- `pyacc-x86-search2` (CPU): `bash kaggle/setup_cpu.sh && rm -rf results/binary64_search/x86_cpu results/binary32_search/x86_cpu && python3 drivers/search.py --fmt binary64 --device cpu --tag x86_cpu --libs numpy,scipy,jax,torch && python3 drivers/search.py --fmt binary32 --device cpu --tag x86_cpu --libs numpy,scipy,jax,torch && python3 -W ignore drivers/verify.py --tag x86_cpu --device cpu; echo ALLDONE`
- `pyacc-x86-probea` (CPU): `pip install -q torch==2.9.1 --index-url https://download.pytorch.org/whl/cpu numpy==2.2.6 >/dev/null 2>&1; python3 drivers/x86_repro_probe.py`
- `pyacc-x86-probeb` (CPU): `pip install -q torch==2.9.1 --index-url https://download.pytorch.org/whl/cpu numpy==2.2.6 >/dev/null 2>&1; python3 drivers/x86_repro_probe.py`
- `pyacc-t4-verify` (T4 GPU): `bash kaggle/setup_gpu.sh && python3 -W ignore drivers/verify.py --tag t4_cuda --device cuda; echo ALLDONE`
- `pyacc-x86-flushfix` (CPU): `bash kaggle/setup_cpu.sh && rm -f results/binary64_search/x86_cpu/jax_*.json results/binary32_search/x86_cpu/jax_*.json && python3 drivers/search.py --fmt binary64 --device cpu --tag x86_cpu --libs jax && python3 drivers/search.py --fmt binary32 --device cpu --tag x86_cpu --libs jax && python3 -W ignore drivers/verify.py --tag x86_cpu --device cpu && python3 -W ignore drivers/verify_extra.py --tag x86_cpu --device cpu; echo ALLDONE`
- `pyacc-t4-extra` (T4 GPU): `bash kaggle/setup_gpu.sh && python3 -W ignore drivers/verify_extra.py --tag t4_cuda --device cuda; echo ALLDONE`
- `pyacc-x86-sqrt` (CPU): `bash kaggle/setup_cpu.sh && python3 drivers/exhaustive.py --fmt binary16 --device cpu --tag x86_cpu --funcs sqrt,rsqrt && python3 drivers/exhaustive.py --fmt bfloat16 --device cpu --tag x86_cpu --funcs sqrt,rsqrt && python3 drivers/exhaustive.py --fmt binary32 --device cpu --tag x86_cpu --funcs sqrt,rsqrt && python3 drivers/search.py --fmt binary64 --device cpu --tag x86_cpu --funcs sqrt,rsqrt && python3 -W ignore drivers/verify.py --tag x86_cpu --device cpu && python3 -W ignore drivers/verify_extra.py --tag x86_cpu --device cpu; echo ALLDONE`
- `pyacc-t4-sqrt` (T4 GPU): `bash kaggle/setup_gpu.sh && python3 drivers/exhaustive.py --fmt binary16 --device cuda --tag t4_cuda --funcs sqrt,rsqrt && python3 drivers/exhaustive.py --fmt bfloat16 --device cuda --tag t4_cuda --funcs sqrt,rsqrt && python3 drivers/exhaustive.py --fmt binary32 --device cuda --tag t4_cuda --funcs sqrt,rsqrt && python3 drivers/search.py --fmt binary64 --device cuda --tag t4_cuda --funcs sqrt,rsqrt && python3 -W ignore drivers/verify.py --tag t4_cuda --device cuda && python3 -W ignore drivers/verify_extra.py --tag t4_cuda --device cuda; echo ALLDONE`
